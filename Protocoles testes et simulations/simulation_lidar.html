1.3 — Implémenter la fonction

Dans lidar_simulator.c, ajoute à la fin du fichier :

void LidarSim_DetectObstacle(
    const LidarFrame *frame,
    uint16_t threshold_mm,
    LidarObstacleInfo *info
)
{
    uint32_t row_sum = 0u;
    uint32_t col_sum = 0u;
    uint32_t distance_sum = 0u;

    info->close_count = 0u;
    info->nearest_mm = 0xFFFFu;
    info->mean_close_mm = 0u;
    info->centroid_row = 0.0f;
    info->centroid_col = 0.0f;
    info->detected = 0u;

    for (uint32_t r = 0; r < LIDAR_HEIGHT; r++)
    {
        for (uint32_t c = 0; c < LIDAR_WIDTH; c++)
        {
            uint16_t d = frame->range_mm[r][c];

            if ((d != LIDAR_INVALID_MM) && (d < threshold_mm))
            {
                info->close_count++;
                distance_sum += d;
                row_sum += r;
                col_sum += c;

                if (d < info->nearest_mm)
                    info->nearest_mm = d;
            }
        }
    }

    if (info->close_count > 0u)
    {
        info->detected = 1u;
        info->mean_close_mm = distance_sum / info->close_count;
        info->centroid_row = (float)row_sum / info->close_count;
        info->centroid_col = (float)col_sum / info->close_count;
    }
}

1.4 — Brancher la fonction dans main.c

Dans USER CODE BEGIN PV, ajoute :

Découpler les types de données du simulateur

REFACTORING CONTRÔLÉ

2.1 — Pourquoi faire cette étape

Actuellement LidarFrame, LidarFrameStats et LidarObstacleInfo appartiennent à lidar_simulator.h. Le futur driver réel ne doit pas dépendre d’un fichier nommé « simulator ».

2.2 — Créer les nouveaux fichiers

Dans STM32CubeIDE :

  1. Clic droit sur FSBL/Core/Inc → New → Header File → lidar_types.h.
  2. Clic droit sur FSBL/Core/Inc → New → Header File → lidar_processing.h.
  3. Clic droit sur FSBL/Core/Src → New → Source File → lidar_processing.c.

2.3 — Déplacer uniquement les types

Dans lidar_types.h, mettre :

#ifndef LIDAR_TYPES_H
#define LIDAR_TYPES_H

#include <stdint.h>

#define LIDAR_WIDTH       54u
#define LIDAR_HEIGHT      42u
#define LIDAR_INVALID_MM  0xFFFFu

typedef struct
{
    uint32_t timestamp_ms;
    uint16_t range_mm[LIDAR_HEIGHT][LIDAR_WIDTH];
    uint16_t amplitude[LIDAR_HEIGHT][LIDAR_WIDTH];
    uint16_t ambient[LIDAR_HEIGHT][LIDAR_WIDTH];
    uint8_t dss[LIDAR_HEIGHT][LIDAR_WIDTH];
} LidarFrame;

typedef struct
{
    uint16_t min_mm;
    uint16_t max_mm;
    uint32_t mean_mm;
    uint32_t invalid_count;
    uint32_t valid_count;
} LidarFrameStats;

typedef struct
{
    uint32_t close_count;
    uint16_t nearest_mm;
    uint16_t mean_close_mm;
    float centroid_row;
    float centroid_col;
    uint8_t detected;
} LidarObstacleInfo;

#endif

2.4 — Déplacer les traitements

Dans lidar_processing.h, déclarer :

#ifndef LIDAR_PROCESSING_H
#define LIDAR_PROCESSING_H

#include "lidar_types.h"

void LidarProcessing_ComputeStats(
    const LidarFrame *frame,
    LidarFrameStats *stats
);

void LidarProcessing_DetectObstacle(
    const LidarFrame *frame,

    LidarObstacleInfo *info

#endif

Dans lidar_processing.c, déplacer/copier les implémentations de statistiques et de détection en les renommant avec le préfixe LidarProcessing_.

2.5 — Adapter le simulateur

Dans lidar_simulator.h :

  • supprime les définitions de LidarFrame, LidarFrameStats, LidarObstacleInfo ;
  • ajoute #include "lidar_types.h" ;
  • conserve seulement les types/fonctions propres au simulateur.

2.6 — Adapter main.c

Ajoute :

#include "lidar_processing.h"

Puis remplace :

par :

et remplace :

par :

2.7 — Tester la non-régression

Refais exactement les tests des phases 0 et 1.

Phase validée si : toutes les valeurs restent identiques après le déplacement des types et traitements.

Convertir profondeur → XYZ sur PC

GÉOMÉTRIE 3D

7.1 — Fichier à créer sur PC

Crée hors du projet STM32, par exemple :

PC_tools/depth_to_xyz.py

7.2 — Paramètres initiaux

WIDTH = 54
HEIGHT = 42
FOV_H_DEG = 55.0
FOV_V_DEG = 42.0

7.3 — Conversion

alpha = -FOV_H/2 + c * FOV_H/(WIDTH-1)
beta  = -FOV_V/2 + r * FOV_V/(HEIGHT-1)

x = d * cos(beta) * cos(alpha)
y = d * cos(beta) * sin(alpha)
z = d * sin(beta)

Convertis les angles en radians avant les fonctions trigonométriques.

7.4 — Gestion des invalides

Si d == 0xFFFF, ne génère aucun point.

7.5 — Test de validation

  1. Utilise la scène FLAT_WALL.
  2. Génère les points XYZ.
  3. Affiche-les en 3D.
  4. Le nuage doit former une surface proche d’un plan.
  5. Avec CENTRAL_OBSTACLE, tu dois voir une surface centrale plus proche que le fond.
Ce modèle angulaire est une approximation de développement. Il faudra utiliser la calibration réelle du capteur plus tard.

Faire une première carte 2D

PREMIÈRE RESTITUTION

8.1 — Fichier PC

Créer :

PC_tools/xyz_to_occupancy.py

8.2 — Méthode

  1. Lire les points XYZ.
  2. Choisir un plan horizontal, par exemple X-Y.
  3. Définir une résolution de grille, par exemple 5 cm/cellule.
  4. Pour chaque point, calculer sa cellule.
  5. Marquer la cellule comme occupée.
  6. Afficher la grille.

8.3 — Test attendu

Avec CENTRAL_OBSTACLE, la carte doit montrer une zone d’occupation plus proche au centre et un fond plus éloigné.

Phase validée si : tu obtiens une image 2D cohérente à partir d’une seule pose simulée.
